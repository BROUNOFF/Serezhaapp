# Game Subscription Service с PostgreSQL

Система управления игровыми подписками с использованием PostgreSQL.

## Требования

- Python 3.8+
- PostgreSQL 12+
- PySide6
- psycopg2

## Установка

1. Установите PostgreSQL на сервере или используйте удаленный сервер
2. Создайте базу данных:
   ```sql
   CREATE DATABASE game_subs_db
